# الهوية البصرية — الورقة الذهبية GPC

أصول العلامة التجارية المستخدمة في صفحات الفريق والبطاقات الرقمية.

## الملفات
| الملف | الوصف |
|------|-------|
| `logo-icon.svg` | علامة الحرف **C** (طيّة ورقة ذهبية). العدّاد الداخلي شفّاف واللون عبر `currentColor` — يعمل على أي خلفية. |
| `brand.css` | نظام التصميم: رموز الألوان + مكوّنات (`.gpc-btn`، `.gpc-chip`، `.gpc-lockup` …). |

> ملاحظة: `logo-icon.svg` **إعادة بناء دقيقة** للشعار كـ SVG متجهي (الملف الأصلي كان صوراً فقط). لأعلى دقة للطباعة، استبدله بملف الشعار الأصلي مع الإبقاء على نفس الاسم — كل الصفحات ستلتقط التحديث تلقائياً.

## لوحة الألوان
| اللون | Hex | المتغيّر |
|------|-----|---------|
| بنفسجي أساسي | `#643DFF` | `--gpc-purple` |
| بنفسجي أفتح | `#7B5CFF` | `--gpc-purple-2` |
| بنفسجي داكن | `#38226B` | `--gpc-purple-dark` |
| بنفسجي أعمق | `#1A0D3D` | `--gpc-purple-deep` |
| ذهبي | `#FFC42E` | `--gpc-gold` |
| ذهبي فاتح | `#FFE195` | `--gpc-gold-2` |
| خلفية فاتحة | `#F8F7FF` | `--gpc-bg` |

مستخرجة من الموقع الرسمي المبني لضمان التطابق.

## الاستخدام
```html
<link rel="stylesheet" href="./brand/brand.css">

<!-- الشعار (يُلوّن عبر color) -->
<span class="gpc-mark" style="width:48px;color:#643DFF">
  <!-- محتوى logo-icon.svg -->
</span>

<a class="gpc-btn gpc-btn--gold">زر ذهبي</a>
<span class="gpc-chip">وسم</span>
```

## الخطوط
- **Noto Kufi Arabic** (أساسي) و **Cairo** — تُحمّل من Google Fonts، مطابقة للموقع.
